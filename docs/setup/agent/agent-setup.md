# Agent Setup

Each agent can be connected to external services. Configure per-agent tokens in `.kitchen.yaml` (env var names) and `.env` (actual secrets).

## Integrations

- [Slack Agent Setup](./slack-agent-setup.md) — receive and respond to Slack messages
- [GitHub Agent Setup](./github-agent-setup.md) — create PRs, list PRs, add comments
- [Linear Agent Setup](./linear-agent-setup.md) — create and manage Linear issues
- [Notion Agent Setup](./notion-agent-setup.md) — search, read, and write Notion pages and databases
